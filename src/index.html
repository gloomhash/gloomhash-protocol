Where figures originate

Public endpoints, queried straight by our script. No relay server, no private cache standing between.

  1. Boost list first

    The top boosted tokens set the cast. Only Solana entries survive the filter.

  2. Pair detail second

    Each token gets its pairs fetched; whichever pair trades most represents it.

  3. Logos with fallbacks

    Should an image fail, a lettered tile steps in; each row retains shape.

  4. Quiet while hidden

    Polling halts while this tab sits hidden, then fires one request upon return.

  5. Growing pauses on failure

    Retries space out exponentially, which spares any struggling source a hammering.

How addresses get judged

Look-alike strings drain wallets. One written record stands between you and them.

  1. One record per fact

    Contract, links and sources each hold a status: stated, absent or unconfirmed.

  2. Absent means inert

    A missing fact renders as a dead control. No link, no copy button, no guesswork.

  3. Shape is never a verdict

    An address-looking string, whichever chain it resembles, is weighed against the registry, never rejected over its form.

  4. The contract slot is exempt

    The pinned address up top is registry content itself, so the scanner skips it.

  5. Handles come from links

    We store the full URL and derive the handle from it. Never the reverse.

Questions

Define GLOOMHASH.

A Solana token teamed alongside one live market terminal. The terminal ranks boosted tokens and pins one row for our own contract.

Where sits the contract address?

It lives inside the strip across the page top. Until one is announced, that strip stays dormant; copying is impossible. Distrust any address displayed elsewhere.

Why does row one look empty?

Lacking a stated contract, no target exists to query. The row retains our mark plus dotted placeholders, then populates automatically once an announcement lands.

Where do prices originate?

Dexscreener supplies ranking and pair data. pump.fun adds artwork and metadata for our own token. Each source answers publicly.

Does a figure ever go blank?

Solely when some source never once replied. After one success, failures leave old figures standing and retry across longer gaps.

Does GLOOMHASH want my wallet?

Never. Nothing resembling a wallet prompt exists. Treat any lookalike requesting a signature as hostile.

Does boosting imply safety?

No. A boost means someone paid for exposure, nothing more. Research each project yourself.

Which facts can the checker confirm?

Only whether your string equals the registry contract. It cannot vouch for any other address.
